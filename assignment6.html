2. Data Preparation

First, we load the Jane Austen books and prepare the data. We create a line number and chapter number for each line of text. Then we select Emma.

# Load Jane Austen's books
austen_data <- austen_books()

# Add line numbers and chapter numbers
austen_data <- austen_data %>%
  group_by(book) %>%
  mutate(
    linenumber = row_number(),
    chapter = cumsum(
      str_detect(
        text,
        regex("^chapter\\s+[0-9ivxlc]+", ignore_case = TRUE)
      )
    )
  ) %>%
  ungroup()

# Select Emma
emma <- austen_data %>%
  filter(book == "Emma")

# Show the first few rows
head(emma)

The austen_books() function loads Jane Austen’s books. We group the data by book and identify chapter headings using regular expressions. The line number and chapter number are added as new columns.

3. Tokenization

Use unnest_tokens() to separate the text into individual words. This allows to compare the words in the novel with the sentiment lexicons.

# Separate the text into individual words
emma_words <- emma %>%
  unnest_tokens(word, text)

# Display the first few words
head(emma_words)

4. NRC Sentiment Analysis

The NRC sentiment lexicon classifies words into different emotions. This analysis focuse on words associated with joy.

# Load the NRC lexicon and select joyful words
nrc_joy <- get_sentiments("nrc") %>%
  filter(sentiment == "joy")

# Match joyful words with words from Emma
emma_nrc <- emma_words %>%
  inner_join(nrc_joy, by = "word")

# Count the frequency of each word
nrc_frequency <- emma_nrc %>%
  count(word, sort = TRUE) %>%
  filter(n > 50)
